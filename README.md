# MyPortfolio

Portfolio personal desarrollado para mostrar mis proyectos, habilidades y experiencia como desarrollador Full-stack.

## Sobre el proyecto

Este sitio web funciona como mi portfolio profesional. Incluye una presentación personal, tecnologías que utilizo, proyectos destacados y una forma de contacto.

## Tecnologías

- HTML / CSS / JavaScript
- React
- Vite
- Git y GitHub

## Objetivo

El objetivo de este proyecto es tener una presencia profesional online donde mostrar mi trabajo, mi stack tecnológico y mi evolución como desarrollador.

## Estructura

- `src/` - componentes, páginas y lógica principal
- `public/` - archivos estáticos
- `assets/` - imágenes y recursos visuales

## Estado

Proyecto en mejora continua. Iré actualizando diseño, contenido y nuevos proyectos.
